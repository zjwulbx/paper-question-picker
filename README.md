# 论文提问抽签

一个完全在浏览器本地运行的课堂论文提问抽签工具。

- 每周 3 篇论文，每篇抽取 3 名学生。
- 同一周的 9 名学生不重复。
- 完成全部论文后，每名学生恰好被抽中 3 次。
- 使用 256 位安全随机种子和固定算法生成可复现的完整安排。
- 抽签前可导出公开承诺凭证；课程结束后可导出完整审计报告，并在本地验证器中重放核对。
- 自动保存当前进度，并记录最近 20 次完整抽签历史。
- 重置后可查看操作记录、恢复原进度或导出历史结果。
- 支持将当前进度和全部历史导出为完整 JSON 备份，并在其他设备上导入恢复。
- 支持复制结果和导出 CSV。

## 可验证抽签流程

1. 输入名单与论文，生成完整安排。
2. 下载“公开承诺凭证”，在第一次揭晓前发到班级群或其他有外部时间记录的渠道。
3. 回到页面确认已经公开，然后按周揭晓。
4. 全部论文结束后导出“完整审计报告”。
5. 学生在本地验证器中分别载入事前凭证和最终报告，核对承诺、随机种子、完整安排和公平规则。

承诺机制证明的是“公开之后没有更换输入、种子或安排”。它本身不能证明组织者在公开之前没有多次生成候选结果；公开凭证中的时间也是本机自报时间，真正的先后证据来自班级群或邮件等外部消息记录。精确的输入编码、随机流、无偏洗牌、排程和承诺公式见 [ALGORITHM.md](ALGORITHM.md)。

学生名单、论文信息、抽签结果和历史存档默认只保存在当前浏览器中，不会上传到服务器。更换浏览器、设备或清除网站数据前，请在“历史存档”中选择“导出完整备份”；之后可在另一台设备上选择“导入备份”恢复。

完整 JSON 备份包含学生名单、论文信息、操作记录、私密随机种子和所有预先生成的抽签安排，包括尚未揭晓的结果。备份文件未加密，请妥善保管，不要上传到公开位置或随意分享；存入微信文件、OneDrive、iCloud、百度网盘等服务时，也请留意相应服务的隐私设置。

公开承诺凭证不含学生姓名、论文标题、随机种子或未来结果，可以在抽签前公开；但其中的未加盐输入摘要不等于匿名化，知道候选名单的人仍可能离线验证猜测。最终审计报告含实名输入、随机种子和全部安排，应只在课程完成后、在合适的班级范围内分享。旧版记录没有事前承诺和种子，仍可查看与恢复，但不能补造为可验证记录。

浏览器存储按域名而不是路径隔离；同一 `zjwulbx.github.io` 域名下的其他页面理论上可以访问这里保存的本地数据。若要长期存放未公开结果，建议为本项目使用独立域名，或只使用受控设备并妥善保管私有备份。
