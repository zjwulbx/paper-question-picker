# 论文提问抽签

一个完全在浏览器本地运行的课堂论文提问抽签工具。

- 每周 3 篇论文，每篇抽取 3 名学生。
- 同一周的 9 名学生不重复。
- 完成全部论文后，每名学生恰好被抽中 3 次。
- 自动保存当前进度，并记录最近 20 次完整抽签历史。
- 重置后可查看操作记录、恢复原进度或导出历史结果。
- 支持将当前进度和全部历史导出为完整 JSON 备份，并在其他设备上导入恢复。
- 支持复制结果和导出 CSV。

在线使用：<https://zjwulbx.github.io/paper-question-picker/>

学生名单、论文信息、抽签结果和历史存档默认只保存在当前浏览器中，不会上传到服务器。更换浏览器、设备或清除网站数据前，请在“历史存档”中选择“导出完整备份”；之后可在另一台设备上选择“导入备份”恢复。

完整 JSON 备份包含学生名单、论文信息、操作记录和所有预先生成的抽签安排，包括尚未揭晓的结果。备份文件未加密，请妥善保管，不要上传到公开位置或随意分享；存入微信文件、OneDrive、iCloud、百度网盘等服务时，也请留意相应服务的隐私设置。
